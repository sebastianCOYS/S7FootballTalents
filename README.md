S7ANALYZE is an AI-integrated football advanced analytics app. You can let AI help you analyze any player and get the most out of their data.

Tech Stack
(built with Vite)

Frontend -
React +(React Router)
TypeScript
Vite
Material UI
Tanstack Query

Backend -
Node.js 
Express +(bucket, express-rate-limit)
MySQL
Groq API -> Llama3.3:70b (formerly Google GenAI)
